# Security Policy

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you discover a security vulnerability in any Mininglamp-OSS project, please report it responsibly:

1. **Email:** Send a detailed report to **security@mininglamp.com**
2. **Include:**
   - Description of the vulnerability
   - Steps to reproduce
   - Affected repository and version/commit
   - Potential impact assessment
   - Any suggested fix (optional but appreciated)

## Response Timeline

| Step | Target |
|------|--------|
| Acknowledgment | Within 48 hours |
| Initial assessment | Within 5 business days |
| Fix or mitigation plan | Within 30 days (severity-dependent) |

## Supported Versions

Each repository documents its own supported versions. As a general policy, only the **latest release** and the **main branch** receive security updates.

## Disclosure Policy

- We follow **coordinated disclosure**: we ask reporters to keep vulnerabilities confidential until a fix is available.
- We will credit reporters in the security advisory (unless anonymity is requested).
- Critical vulnerabilities will be patched and disclosed as quickly as possible.

## Scope

This policy applies to all public repositories under the [Mininglamp-OSS](https://github.com/Mininglamp-OSS) organization.

Thank you for helping keep Mininglamp-OSS and its users safe.
