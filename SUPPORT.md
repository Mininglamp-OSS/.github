# Getting Help

Thanks for using Mininglamp-OSS projects! Here's how to get help.

## Before You Ask

1. **Search existing issues** in the relevant repository — your question may already be answered.
2. **Read the docs** — check the repository's README and any linked documentation.

## Where to Get Help

| Channel | Use for |
|---------|---------|
| **GitHub Issues** | Bug reports, feature requests (use the provided templates) |
| **GitHub Discussions** | Questions, ideas, general conversation |

> 📌 More community channels (Discord, forums, etc.) will be announced as the project grows.

## What NOT to Use Issues For

- General "how do I…" questions → use Discussions
- Security vulnerabilities → see [SECURITY.md](SECURITY.md)

## Helping Us Help You

When asking for help, please include:

- **What you're trying to do** (goal, not just the error)
- **What you've already tried**
- **Environment details** (OS, runtime version, relevant config)
- **Error messages or logs** (formatted as code blocks)
