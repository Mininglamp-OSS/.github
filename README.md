# .github

Organization-wide community health files and shared templates for [Mininglamp-OSS](https://github.com/Mininglamp-OSS).

## What's in this repo

| File | Purpose |
|------|---------|
| `profile/README.md` | Organization profile shown on the [org landing page](https://github.com/Mininglamp-OSS) |
| `CONTRIBUTING.md` | Contributing guidelines (applied to all repos without their own) |
| `CODE_OF_CONDUCT.md` | Contributor Covenant Code of Conduct |
| `SECURITY.md` | Security vulnerability reporting policy |
| `SUPPORT.md` | Where and how to get help |
| `ISSUE_TEMPLATE/` | Shared issue templates (bug report, feature request) |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template |
| `FUNDING.yml` | GitHub Sponsors configuration |
| `LICENSE` | License for this repository's content |

## How GitHub uses these files

GitHub automatically applies community health files from the `.github` repository to all public repositories in the organization that don't have their own. See [GitHub docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for details.
